QUICK START · 60 SECONDS

From download
to scanning the QR code.

Zero cloud accounts required and nothing to install from mobile app stores.

git clone https://github.com/raults32/ChromeRemoteControl.git
cd ChromeRemoteControl && .\start.bat

  1. Extract and launch start.bat

    Download the release ZIP, extract it, and double-click start.bat (or ./start.sh on macOS/Linux). It sets up the environment automatically and launches the system tray icon.

  2. Load the Chrome MV3 Bridge

    Open chrome://extensions, enable «Developer mode» in the top-right corner, click «Load unpacked», and select the included chrome-extension folder. The ON badge lights up right away.

  3. Scan the QR code from your phone

    On the same Wi-Fi network, scan the QR code shown in the console or via «View QR Code & PIN» in the system tray to authorize a persistent session token.

  4. Add to Home Screen (PWA)

    In Android Chrome tap «Install app» and in iPhone Safari tap «Share → Add to Home Screen» for a borderless fullscreen remote.

FREQUENTLY ASKED QUESTIONS

Everything clear before downloading.

Does my data or screen ever leave my home network?

Never. All WebSocket traffic stays strictly inside your local Wi-Fi network between your phone and PC, guarded by PIN verification and session tokens.

What if I use another browser or have not loaded the extension yet?

The backend automatically falls back to native OS shortcuts so the trackpad, keyboard, audio, screen spy, navigation, and basic playback keys continue working seamlessly.

Does «Screen Spy» consume CPU when closed?

Zero percent. Screen capture stays completely idle until you actively open the «Screen Spy» view on your phone.

What are the system requirements?

Python 3.11+ on your PC (the mobile PWA is already prebuilt inside the release package) and any modern browser on Android or iOS connected to the same Wi-Fi.
